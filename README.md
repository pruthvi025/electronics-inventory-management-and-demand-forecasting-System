# 📦 Inventory Management & Demand Forecasting System

A full-stack industry-grade web application for electronics retail businesses.  
The system manages inventory, tracks stock movement, processes sales, manages suppliers & purchase orders, and predicts future product demand using machine learning.

Built by a team of three developers as a minor project.

---

## 🚀 Tech Stack

### **Frontend**
- React (Vite) + TypeScript  
- Axios for API integration  
- Recharts / Chart.js for analytics  
- Modern Figma-designed admin UI  

### **Backend**
- FastAPI (Python)  
- SQLAlchemy ORM  
- JWT Authentication  
- Pydantic validation  

### **Database**
- PostgreSQL / MySQL  

### **AI & Forecasting**
- Google Vertex AI  
- Time-series forecasting  
- Stock-out prediction  
- Reorder recommendations  

### **Tools**
- GitHub for team collaboration  
- VS Code  
- Docker (optional)  

---

## 🔧 Key Features

### 🧮 Inventory Management
- Add, edit, delete products  
- Real-time stock tracking  
- SKU/Barcode support  
- Auto stock adjustment after sales  

### 📥 Stock In / 📤 Stock Out
- Stock entry with supplier & invoice reference  
- Stock-out logging with reason (sale, damage, replacement)  
- Full transaction history  

### 💰 Sales Module
- Manual sales entry  
- Bulk CSV upload  
- Daily & monthly sales insights  

### 🧾 Purchase Orders
- Create/manage POs  
- Supplier linking  
- Status workflow: Draft → Pending → Received  
- Export PO as PDF  

### 🧑‍🤝‍🧑 Supplier Management
- Add/manage suppliers  
- View supplier activity  
- Link suppliers to POs  

### 📈 AI-Powered Demand Forecasting
- Vertex AI-based forecasting  
- Predicted stock-out dates  
- Recommended reorder quantity  
- Past vs future trend charts  

### 📊 Reports & Analytics
- Sales reports  
- Inventory valuation  
- Category-wise stock data  
- Forecast accuracy  

### 🔐 Authentication & Roles
- JWT login  
- Role-based access (Admin, Staff, Viewer)  
- User management panel
